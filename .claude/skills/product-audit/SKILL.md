# Product Audit Skill

## Goal
Find the biggest bottlenecks and the highest-leverage improvements.

## Steps
1. **Identify Target User**: Who is this audit for?
2. **First Value Moment**: Define the value proposition trigger.
3. **Audit Onboarding**: Inspect onboarding flow for drop-off steps.
4. **Audit Core Flow**: Review search, song player, translation explain engine.
5. **Audit Monetization**: Check paywall triggers, plan limitations, Stripe checkouts.
6. **Audit Analytics**: Check active metrics collection.
7. **Prioritize**: Group tasks into high impact / low effort wins first.
8. **Pareto Action Plan**: Provide a 7-day action blueprint.

## Output
- **Diagnosis**: Found issues.
- **Biggest Bottleneck**: The primary friction point.
- **Quick Wins**: Simple fixes.
- **7-day Plan**: Development roadmap.
- **Metrics**: KPIs to monitor.
