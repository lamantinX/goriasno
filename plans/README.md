## Архитектура и стек проекта

Сайт спроектирован как ультра-оптимизированное React-приложение:
*   **Сек**: React 19, Vite 6, TypeScript, Tailwind CSS v4 (с плагином `@tailwindcss/vite`), Lucide React для иконок, Framer Motion (`motion`) для анимаций.
*   **Дизайн**: Идентичный согласованному макету (глубокий темный стиль "угольный" `#0a0a0c`, огненные желто-оранжевые акценты). Полная мобильная адаптивность.
*   **Оптимизация производительности для РФ**:
    *   *Self-Hosted*: Все шрифты (WOFF2) и ресурсы хранятся локально (отказ от внешних CDNs).
    *   *Ленивая загрузка медиа*: Атрибуты `loading="lazy"` на всех изображениях каталога.
    *   *Ленивая загрузка карт*: Интерактивная Яндекс.Карта подгружается через iframe динамически по запросу (IntersectionObserver или клик-оверлей), экономя трафик при загрузке.
    *   *Offline-first (PWA)*: Настройка Service Worker в сборщике Vite для кэширования основных файлов, стилей и шрифтов на устройстве пользователя.
    *   *Безопасный Telegram-релей*: На сервере разворачивается безопасный Express.js бэкенд (`server.js`), который принимает заявки с фронтенда и пересылает в Telegram-канал владельца. Токен бота хранится в файле `.env` и никогда не утекает на клиент.
    *   *Сжатие и кэширование*: Конфигурации для Nginx/Docker с кэшированием статики и сжатием Brotli/Gzip.
    *   *Соответствие законодательству РФ*: Согласие с обработкой персональных данных (ФЗ-152) под формами, ссылка на Политику конфиденциальности, реквизиты ИП и дисклеймер оферты по ст. 437 ГК РФ.
