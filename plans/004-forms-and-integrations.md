## Зачем это нужно

Для надежного получения заявок и уведомления владельца о новых лидах:
1.  **Интеграция с Telegram-ботом**: Сайт должен отправлять заполненные формы (Имя, Телефон, Выбранный товар, Сообщение) прямо в Telegram-чат владельца склада.
2.  **Безопасный бэкенд-релей (`server.js`)**: Токен Telegram-бота и ID чата ни в коем случае не должны передаваться клиенту (JS на фронтенде). Мы развернем простой бэкенд на Express.js, который считывает секреты из `.env` и безопасно отправляет запросы к Telegram API.
3.  **Соответствие ФЗ-152 (О персональных данных)**: Под всеми формами согласия должен быть обязательный чекбокс согласия с обработкой персональных данных и ссылка на Политику конфиденциальности.
4.  **Соответствие ГК РФ (ст. 437)**: В подвале должны быть указаны реквизиты предпринимателя и оговорка о том, что информация на сайте не является публичной офертой.

## Текущее состояние

Форма обратной связи в `FeedbackSection.tsx` и модальное окно в `Modal.tsx` работают только на локальном состоянии React и сохраняют лиды в `localStorage`. Бэкенд отсутствует. Соответствие ФЗ-152 текстовое, без обязательных чекбоксов.

## Шаги реализации

### Шаг 1: Создание Express.js сервера (`server.js`)
*   Создайте файл `server.js` в корне проекта.
*   Напишите обработчик маршрута `POST /api/leads`:
    *   Принимает параметры `name`, `phone`, `productName`, `message`, `sourceForm`.
    *   Формирует сообщение для Telegram с эмодзи.
    *   Выполняет запрос к `https://api.telegram.org/bot<TOKEN>/sendMessage` с использованием `fetch` (встроенного в Node.js).
    *   Считывает `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` из `process.env`.
*   Настройте отдачу статических файлов из папки `dist/` для продакшена, чтобы запускать весь проект одной командой.

### Шаг 2: Создание конфигурации `.env`
*   Создайте файл `.env` в корне проекта (проверьте, что `.env` находится в `.gitignore`):
    ```env
    PORT=3001
    TELEGRAM_BOT_TOKEN=your_bot_token_here
    TELEGRAM_CHAT_ID=your_chat_id_here
    ```
*   Создайте шаблон `.env.example` для справки.

### Шаг 3: Настройка прокси в `vite.config.ts`
*   В конфигурацию Vite добавьте секцию `server.proxy` для разработки:
    ```typescript
    server: {
      proxy: {
        '/api': {
          target: 'http://localhost:3001',
          changeOrigin: true,
        }
      }
    }
    ```

### Шаг 4: Обновление React-форм и добавление чекбокса ФЗ-152
*   В `src/components/FeedbackSection.tsx` и `src/components/Modal.tsx`:
    *   Добавьте состояние чекбокса `const [agree, setAgree] = useState(false)`.
    *   Рядом с кнопкой отправки выведите чекбокс:
        ```tsx
        <label className="flex items-start gap-2 text-[10px] text-slate-500 cursor-pointer">
          <input 
            type="checkbox" 
            checked={agree} 
            onChange={(e) => setAgree(e.target.checked)} 
            required 
            className="mt-0.5 rounded border-slate-900 bg-slate-950 text-orange-500" 
          />
          <span>Я согласен на обработку персональных данных согласно <a href="/privacy.html" target="_blank" className="underline hover:text-white">Политике конфиденциальности</a></span>
        </label>
        ```
    *   В обработчике `handleSubmit` замените сохранение в `localStorage` на реальный POST-запрос `fetch('/api/leads', ...)` в формате JSON.
    *   При успешном ответе вызывайте `onSubmitSuccess`.

### Шаг 5: Создание Политики конфиденциальности (`public/privacy.html`)
*   Создайте файл `public/privacy.html` со стандартным содержанием политики обработки персональных данных в соответствии с требованиями Федерального закона РФ № 152-ФЗ.

### Шаг 6: Проверка работы
*   Запустите бэкенд и фронтенд: `npm run dev` (или параллельно `node server.js`).
*   Проверьте валидацию (кнопка отправки не должна работать без галочки согласия).
*   Отправьте тестовую заявку, убедитесь, что она пришла в Telegram-чат и не произошла утечка токена.
