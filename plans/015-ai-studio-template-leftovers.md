## Why this matters

This project was generated from an "AI Studio" React template and still
carries its leftovers, which actively harm onboarding: (1) two dependencies
— `@google/genai` (~large Gemini SDK) and `motion` (Framer Motion) — are
declared in `package.json` but imported nowhere in `src/` or `server.js`
(grep-confirmed); they inflate install time, disk, and the supply-chain
attack surface for zero benefit. (2) `README.md` is the AI Studio template
("Set the GEMINI_API_KEY…") — it doesn't describe this project (a coal
warehouse catalog) or how to actually run its Express+Telegram backend. (3)
`.env.example` documents `GEMINI_API_KEY` and `APP_URL` (both unused) but
OMITS the actually-required `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, and
`PORT` that `server.js` reads — so a new contributor cannot configure the
backend from the example. (4) `plans/README.md:24` falsely claims "Framer
Motion (motion) для анимаций" (animations are CSS keyframes + Tailwind
`animate-*` utilities, not Framer Motion). This plan removes the dead deps
and makes the docs tell the truth.
